- Protocolo IPv4:
	- Possibilita o encaminhamento de diferentes tipos de tráfego (voz, vídeo e dados)
- ![[Captura de Tela 2026-04-28 às 19.41.43.png]]
	- Cabeçalho padrão: 20 bits (típico) e pode chegar até 60bits Versão, comprimento do cabeçalho (não é fixo), tipo de serviço (qualidade de serviço(QoS)(atender diferentes tipos de tráfego) ), comprimento do datagrama (bytes), identificador de 16 bits, flags, deslocamento de fragmentação (13 bits), tempo de vida (se for 0 o roteador descarta o pacote, cada roteador decrementa um valor, útil em loops de roteamento), protocolo da camada superior (diz o que está encapsulado na parte de dados do IP), soma de verificação do cabeçalho (normalmente é tudo 0, não usa)
- Pilha dupla: Tanto IPv4 quanto IPv6
- IHL (??)
- ICMP: Conjunto de mensagens  (fica em dados no IP e em dados na camada 2)
- Comprimento do cabeçalho: ``Quantidade de bytes/4`` 
- Comprimento do pacote: Quantidade de bytes
- Deslocamento de fragmentos: ``Quantidade de bytes/8`` (acha o máximo de comprimento)
- MTU
- Fragmentação: 000 é o último fragmento
- Bit de flag 0: Não tem mais fragmento 
- Bit de flag 1: tem mais bytes
- Protocolo ICMP: Um conjunto de mensagens, caso o IP de problema (IP é não orientado) passa o erro para a origem
