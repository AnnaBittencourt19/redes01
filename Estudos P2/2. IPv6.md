## Cabeçalho
- Apenas 8 campos fixos
- Tamanho fixo: 40 octetos
- Maior flexibilidade e eficiencia
- Classe de tráfego: QoS nativo

- 64 para interface ID
## Endereço 
- 8 campos de 16 bits
- '::' só é permitido uma única vez para omitir 0s
- Tabela de rotas: show ipv6 route
- Tem 3 tipos de endereços:
	- Unicast: Comunicação um para um. 64 bits : n para prefixo de roteamento global (com 3 já sendo usados), 64-n para ID da sub-rede e 64 para identificador da interface
	- Anycast: Para o mais próximo do roteador de origem (um para um de muitos)
	- Multicast: Grupo. Comunicação um para muitos
- Link local: baseado no endereço MAC
## Mecanismo de coexistência e transição IPv4 e IPv6
- Pilhas duplas: Os nós são capazes de enviar e receber pacotes tanto para o IPv4 quanto para o IPv6 (nos dispositivos)
- Tunelamento: Transmitir pacotes IPv6 através da infraestrutura IPv4 (encapsulamento IPv6 em IPv4 e desencapsula de IPv4 para IPv6)
- Tradução: cabeçalho ipv4 para ipv6 e vice-versa

- O ICMP (_Internet Control Message Protocol_ ou Protocolo de Mensagens de Controle da Internet) é um protocolo da camada de rede usado por dispositivos (roteadores/hosts) para comunicar erros e informações operacionais, como a indisponibilidade de um serviço ou falha no roteamento de pacotes (base para o ping)
